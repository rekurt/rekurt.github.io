# OpenKline: replay candles in vanilla JavaScript, React and Vue

Press **Next step** twice. The first click adds a forming candle; the second changes that candle's close and volume without adding another bar. Then try **Inspect history** and keep stepping: the view stays where you left it.

The Vanilla, React and Vue tabs run the same sequence through **OpenKline core 0.2.0**. The wrappers are version **0.1.0**. All prices in the replay are synthetic.
